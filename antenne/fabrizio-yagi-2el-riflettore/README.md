## Note

- Elementi montati **verticali**: polarizzazione verticale, come le altre antenne della rete.
- L'elemento alimentato è il più corto: grazie all'accoppiamento con il riflettore l'impedenza scende vicino a 50 Ω e il cavo si collega direttamente.
- Il file è trascritto dalla foto dell'originale. In spazio libero; sul tetto contano l'asta metallica verticale sotto il boom, il percorso del coassiale e i pannelli vicini.
